# Public release evidence status (2026-11-26)

This is a dated inventory of evidence on `main`, open draft work, and the
remaining decisions for an **unattended public release**. It does not grant
permission to enable a provider or to run a real employer application. The
exit criteria remain in [autonomy release requirements](autonomy-release-requirements.md)
and the [monitored beta protocol](monitored-beta-protocol.md).

| Gate | Evidence on `main` | Still required before public use |

[#75](https://github.com/joshuaraja1/openapply-agent/issues/75) remains open; do not claim coverage of every job site. |

The release owner should record a dated go/no-go decision with the supported
OS/provider matrix, exact build and CI links, real-site and beta evidence,
privacy/site-terms review, signing and OAuth status, external security findings,
open defects, and rollback owner. Keep public unattended application disabled
until all gates pass or narrow the advertised scope and repeat the decision for
that scope. Student subscriptions in [#120](https://github.com/joshuaraja1/openapply-agent/issues/120)
are a later product decision, not evidence for this release.
