# Private owner inspection service (staging)

This service is an inactive slice of [issue #153](https://github.com/joshuaraja1/openapply-agent/issues/153). It runs on a user-owned Unix socket in a private directory. A browser-owning process may register an opaque tab ID and a read-only inspection callback. A separate worker process can reconnect and request evidence for that exact tab, claim, official URL, package hash, and artifact hash. Requests and replies are authenticated for one owner generation; replay, changed bindings, and off-requisition URLs fail closed. Tests kill and restart worker processes while the owner service remains alive.

An experimental read-only proxy can register an owner-held Chromium tab and accept one exact-URL navigation and snapshots. Registration installs a same-origin GET/HEAD request gate and closes WebSockets; it requires a runtime launched with service workers blocked. A controlled Chromium test blocks an automatic page-script POST and WebSocket, kills a worker after a snapshot, and reconnects another worker to the same owner generation and page, with existing form state still present. It rejects changed claims, repeated navigation, and every fill/select/upload/click/submit request. Form field events can run page JavaScript that submits an application, so writes require a durable submit journal and a stronger request gate before this protocol may expose them.

The service itself does **not** launch a browser process, dispatch a final click, or mark a job submitted. The application runner still closes its owned browser in `finally`; no production command calls this service. Windows is disabled until named-pipe ACLs are implemented and tested. An uncertain submission still needs the existing candidate-assisted employer receipt check.

Before activating this path, launch and supervise the separate browser owner as a product command; store its private secret in the OS secret store; add guarded multi-step and final-submit operations with a durable click intent; prove one click under crash fault injection; bind a visible employer receipt to the same live tab, requisition, company, role, and saved artifact; then test the exact providers on consented sites. The socket directory must be created as a private user-owned directory before starting the owner.
